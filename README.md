# C・B・B

「チャージ・ビーム・バリア」の3択を同時に出して戦う、読み合い型の対戦ゲームです。Android向けUnityプロトタイプとして開発中です。

## 現在の内容

- CPU戦
- CPU難易度「普通」「強い」
- チャージ・ビーム・バリアの同時選択
- 5チャージ勝利とビーム勝利
- サドンデス
- 7ポイント先取
- スマートフォン縦画面向けUI
- 起動画面、タイトル画面、仮キャラクターと仮エフェクト
- プレイテストログ機能

## 開発環境

- Unity 6000.4.5f1
- Universal Render Pipeline
- 対象：Android（予定）

## 起動方法

1. Unity Hubで「追加」から、このリポジトリのフォルダを選択します。
2. Unity 6000.4.5f1でプロジェクトを開きます。
3. `Assets/Scenes/Main.unity`を開きます。
4. Unity上部の再生ボタンを押します。

## 状況

現在はゲームルール、CPU対戦、縦画面UIを検証するプロトタイプ段階です。キャラクターデザイン、オンライン対戦、ランクマッチ、効果音などは今後実装予定です。
