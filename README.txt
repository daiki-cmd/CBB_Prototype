C・B・B CPU対戦プロトタイプ

Unity 6000.4.5f1用です。

起動方法
1. Unityでこのフォルダをプロジェクトとして開きます。
2. 初回インポートとコンパイルが終わるまで待ちます。
3. Assets/Scenes/Main.unityが自動生成されます。
4. 画面上部の再生ボタンを押します。

試作版の内容
・3Dの簡易対戦画面
・チャージ、ビーム、バリア
・CPU対戦
・CPU難易度「普通」「強い」（試合開始前に選択）
・初期難易度は「普通」
・スマホ縦画面向け日本語UI
・プレイヤーを手前、CPUを奥に置いた奥行き対面レイアウト
・Unity表記入り起動画面
・CPU戦／ランクマッチを選ぶタイトル画面（ランクマッチは準備中）
・通常得点
・5チャージ勝利
・サドンデス
・7ポイント先取
・再戦

操作
CHARGE：チャージを1増やします。
BEAM：チャージを1消費して攻撃します。
BARRIER：ビームを防ぎます。

プレイテストログ
・手動対戦は試合終了時に自動記録されます。
・画面下部の「強いCPUを20試合テスト」で、ChatGPT方針AI対CPUを20試合実行できます。
・ログ保存先：PlaytestLogs/CBB_playtest_log.csv
・勝者、試合時間、ラウンド数、総ターン数、各行動回数、勝ち方、サドンデス回数を記録します。
